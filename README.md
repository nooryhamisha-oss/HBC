# HBC Digital Skills Training Dashboard

A React-based web application prototype designed to support the management and monitoring of the HBC digital skills training program.

## 📌 About the Project

The HBC Digital Skills Training Dashboard is a front-end project developed to provide a centralized interface for managing digital skills training activities. It aims to make program information, learning resources, participants, instructors, projects, and graduate-related information easier to organize and access.

The project is designed as a foundation for a more comprehensive program management system, with potential future integration of a backend, database, and reporting features.

## ✨ Features

* **Dashboard:** An overview interface for program-related information.
* **Learning Tracks:** Pages for exploring digital skills training areas.
* **Participants Management:** Interfaces for organizing participant information.
* **Projects:** A dedicated area for practical projects and learning activities.
* **Instructors:** Pages for instructor-related information.
* **Learning Materials:** Interfaces for accessing learning resources.
* **Graduates:** A section for graduate-related information.
* **Internships:** An area for internship-related opportunities.
* **AI Tools:** Pages introducing AI-related tools and assistance.
* **Authentication Interfaces:** Login and logout pages.
* **Settings:** A page for application settings.
* **Responsive UI:** A web interface built with modern front-end technologies.

## 🚀 Getting Started

### Prerequisites

Install a recent version of Node.js and npm.

### Installation

Clone the repository:

```bash
git clone https://github.com/nooryhamisha-oss/HBC.git
```

Navigate to the project directory:

```bash
cd HBC
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will display a local development URL in the terminal.

### Build for Production

To create a production build, run:

```bash
npm run build
```

The generated production files will be placed in the `dist` directory.
