# HBC Programme Management — frontend prototype

## Requested pages only
1. Landing page (`/`)
2. Login (`/login`)
3. Dashboard (`/dashboard`)
4. Participants (`/students`)
5. Learning tracks (`/find-program`)
6. Instructors (`/find-instructor`)
7. Graduates (`/graduates`)
8. Projects (`/projects`)
9. Internships (`/internships`)
10. Reports & expenses (`/reports`)
11. AI Assistant (`/ai-assistant`)
12. Settings (`/settings`)

Log out is available from the shared sidebar/header (`/logout`). The navigation excludes extra menu entries.

## Run locally
- `npm install`
- `npm run dev`
- `npm run build`

## Integration notes
This is a frontend prototype. AI Assistant is not connected to an AI provider or programme database. Settings currently save basic preferences to local browser storage only. Authentication and data persistence require backend integration. Demo records must not be treated as verified programme data.
